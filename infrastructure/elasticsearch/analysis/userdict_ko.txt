# nori 사용자 사전 — mecab-ko-dic 기본 사전에 없어 nori가 음절 단위로 쪼개 버리는 단어를
# 단일 명사 토큰으로 강제 인식시킨다.
#
# 등재 기준 (project-index-settings.json이 decompound_mode: none 이라는 점이 핵심):
#   여기 등재하면 그 단어는 '쪼갤 수 없는 한 덩어리'가 된다. 즉 "롱패딩"을 등재하면
#   "패딩" 검색으로는 더 이상 안 잡힌다. 그래서 아래 두 조건을 다 만족할 때만 등재한다.
#     1) nori가 뜻이 없는 조각으로 부숴 버린다   — 밀키트→[밀,키트], 치발기→[치,발기], 에어팟→[에,어,팟]
#     2) 그냥 두면 뜻이 뒤집히거나 사라진다      — 간편식→[간,편식](편식!), 무설탕→[무,설탕](설탕!)
#   반대로 쪼개진 조각이 그 자체로 쓸모 있는 검색어면 등재하지 않는다.
#   롱패딩→[롱,패딩], 가죽벨트→[가죽,벨트], 실버목걸이→[실버,목걸이]는 쪼개진 편이 낫다.
#
# synonym.txt의 키는 여기 없어도 된다 — synonym_graph는 규칙을 같은 토크나이저로 분석해
# 여러 토큰짜리 키("스마트글라스"→[스마트,글라스])도 그대로 매칭한다.
#
# 대상 어휘는 운영 서버의 실제 프로젝트 카탈로그(2026-08-31 기준 82건) 기준.
# 변경 시 `_analyze`로 실제 토큰을 확인하고 넣을 것. 감으로 넣으면 위 1)2)를 놓친다.
